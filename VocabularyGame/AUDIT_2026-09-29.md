# Vocabulary Game audit — 2026-09-29

Source of truth: GitHub repository `mthitic-art/vocabulary-game1`, branch `main`,
HEAD `1373398f4e8a7b59c1047eedbe3b071e670da853` at audit start.

## Current state found

- Static browser game hosted from `VocabularyGame/`.
- Data layer is `data/vocabulary.json`; progress is localStorage-only.
- Six game activities plus Word Detective are wired from `js/game.js`.
- Vocabulary data currently contains real content for **June, July, August, September** only.
- The existing month UI listed only 10 months and omitted **March** and **April**.
- Existing CEFR display was hard-coded in `game.js` and used non-standard labels such
  as `A1+`, `A1-A2`, and `A2+`; vocabulary entries had no `cefr` field.
- The repository already has substantial image coverage under `assets/<LEVEL>/`,
  with emoji and word-tile fallback behavior.
- `Summary_Vocabulary.xlsx` is recorded by the generated JSON as the source workbook.
  The generated data reports only June–September as available; therefore October–May
  vocabulary must not be fabricated from image filenames or memory.
- The documented Excel converter and the deployed JSON shape had drifted: the app
  expects a multi-month `{_meta, months}` structure, while the converter's prior
  output path still built a flat merged level object.

## Changes in this branch

1. Canonical school year is now **June → May**, all 12 months.
2. Empty months remain locked but are present in the schema, so new source data can be
   added without code changes.
3. CEFR is a first-class per-word field supporting **Pre-A1, A1, A2, B1, B2**.
4. Existing June–September words receive conservative grade defaults derived from the
   project's previous level labels; future source data can override CEFR per word.
5. The Excel converter now emits the same multi-month schema that the app consumes.
6. `tools/validate_vocabulary.py` audits month coverage, CEFR, duplicates and image
   references, with `--require-full-year` for release gating.

## Content still required from the source workbook

The codebase is ready for a full academic year, but the repository does not currently
contain authoritative October–May vocabulary content. To complete content safely,
add those month sheets/rows to `Summary_Vocabulary.xlsx`, run the converter, run the
validator, and commit both the workbook and regenerated JSON.

## Image policy

- Keep canonical files at `assets/<LEVEL>/<slug>.<ext>`.
- JSON stores an `image` path only when the file exists.
- Prefer WebP/JPEG for size; the runtime already supports WebP/JPEG/JPG/PNG fallback.
- For K1–K3, an emoji fallback is strongly recommended even when an image exists.
- Do not derive curriculum words from asset filenames; assets support vocabulary data,
  not the other way around.

## CEFR policy

- Valid bands: `Pre-A1`, `A1`, `A2`, `B1`, `B2`.
- Current fallback mapping:
  - K1–K2 → Pre-A1
  - K3, P1–P2 → A1
  - P3–P4 → A2
  - P5–P6 → B1
- B2 is supported by schema and validation for future/extension content.
- A per-word `cefr` value in source/generated data overrides the grade fallback.
